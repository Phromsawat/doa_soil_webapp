DOA Soil Analysis — AI-Powered Soil Quality Mobile Web Application
JAN 2026 – MAY 2026
Introduction

DOA Soil Analysis คือ Progressive Web App (PWA) สำหรับวิเคราะห์คุณภาพดินด้วยชุดทดสอบดิน ของกรมวิชาการเกษตร ระบบช่วยให้เกษตรกรสามารถ อัพโหลดภาพถ่ายสีดิน แล้วเทียบสีด้วย AI Color Matching หรือกรอกผลด้วยตนเอง จากนั้นระบบแนะนำ สูตรปุ๋ย (Fertilizer Recommendation) ที่เหมาะสมกับพืชแต่ละชนิด รองรับการใช้งาน (ไทย/อังกฤษ) พร้อม UI ที่ใช้งานง่ายบนมือถือทุกรุ่น และบันทึกประวัติการวิเคราะห์ของผู้ใช้แต่ละคนได้อย่างปลอดภัย

My Role

รับผิดชอบกระบวนการพัฒนาแบบ Full-Stack ทั้งหมดของโปรเจกต์ ตั้งแต่การออกแบบสถาปัตยกรรมระบบ (Architecture) การพัฒนา Front-End ด้วย Next.js 15 ไปจนถึงการเขียน Back-End API จัดการฐานข้อมูล (Supabase / PostgreSQL) การใช้ AI Vision API วิเคราะห์สีดิน และการ deploy บน Vercel พร้อมทดสอบกับผู้ใช้จริง
