# Reference Documents

## `100__ตารางคำนวณปุ๋ยสำหรับ KM ไม้ผล_04.08.2569.xlsx`

ตารางคำนวณปุ๋ยสำหรับไม้ผล 9 ชนิด — จัดทำโดยกรมพัฒนาที่ดิน (LDD)

**Source**: กรมพัฒนาที่ดิน กระทรวงเกษตรและสหกรณ์
**Date**: 04.08.2569 (พ.ศ.) = 04.08.2026

### โครงสร้าง

- 9 sheet ตามชนิดไม้ผล: ทุเรียน, มังคุด, เงาะ, มะม่วง, ลำไย, ลิ้นจี่, ส้ม, มะพร้าว, สับปะรด
- แต่ละ sheet มี 27 rows (3 OM × 3 P × 3 K combinations)
- แต่ละ row ให้ปริมาณปุ๋ย (กรัม/ต้น) แบ่งเป็น 4 ระยะ × 3 สูตร:
  - ระยะ: บำรุงต้น, สร้างตาดอก, บำรุงผล, ปรับปรุงคุณภาพ
  - สูตร: 46-0-0 (ยูเรีย), 18-46-0 (DAP), 0-0-60 (KCl)

### เกณฑ์แบ่งระดับ

| ธาตุ | ต่ำ | ปานกลาง | สูง |
|---|---|---|---|
| OM (%) | <2 | 2–3 | >3 |
| P (มก./กก.) | <15 | 15–45 | >45 |
| K (มก./กก.) | <50 | 50–100 | >100 |
